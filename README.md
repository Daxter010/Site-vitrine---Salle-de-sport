# Base de Connaissances IoT & Dashboard

> Projet développé dans le cadre d'un service technique et de la validation du diplôme (Bac+2 Développeur Web).

## 🚀 Présentation
Application web centralisant la documentation technique, le glossaire des composants IoT et un tableau de bord de suivi pour le matériel.

## 🛠️ Technologies
- HTML5 / CSS3 / JavaScript
- Bootstrap
- Node.js

## 📂 Structure du projet
- `src/` : Code source et scripts
- `public/` : Assets, images et styles
- `config/` : Fichiers de configuration
- `dist/` : Version compilée / optimisée
