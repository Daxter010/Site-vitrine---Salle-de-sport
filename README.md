# Site Vitrine & Gestion de Stock — Salle de Sport (Projet Diplômant)

> **Note :** Ce projet a été réalisé exclusivement dans le cadre d'un examen pour la validation de mon diplôme (Bac+2 Développeur Web). Il s'agit d'un projet d'études et non du site officiel de l'établissement.

## 📌 Présentation du projet
Développement d'un site vitrine dynamique présentant les services d'une salle de sport (découverte de l'établissement, coachs, cours collectifs, événements et produits). 

Le projet intègre également un espace administrateur dédié à la gestion des stocks de produits dérivés et suppléments (CRUD, suivi des quantités et interface de gestion).

## 🛠️ Technologies utilisées
- **Front-end :** HTML5, CSS3, JavaScript, Bootstrap
- **Back-end / Gestion :** PHP / Base de données (CRUD)
